6

関所が、危険な操作を実際に止めた

関所の正式な名前は、フック（Hooks）

AIが操作を出す

→

PreToolUse
危険な型と一致するか

→

一致しない → 実行

一致する → 停止

フックとは、決まったタイミングで必ず自動的に走る仕掛けのことです。
PreToolUse は「AIが道具を使う直前」に割り込む種類で、実行そのものをさせません。

資料の調査中、AIが出したフォルダの一括削除を実際に止めました。現場のポカヨケと同じ発想です。

7

いつ読まれるのか

説明文は常に、本文は呼ばれたときだけ

常に読まれる

冒頭の説明文。入れてあるあいだ、使わなくても毎回読まれ続けます。

呼ばれたときだけ読まれる

手順の本文。ただし一度呼び出すと、読み込んだあとも残ります。

二段構えの名前は、段階的開示（progressive disclosure）

薄い情報を見せておいて、必要になった段階で深い情報を開く設計です。自分で作るときの指針になります。

どこに入れるか

案件の中だけか、いつでも使えるかを選ぶ

プロジェクトスキル

  • 案件のフォルダの .claude/skills/
  • 開いている案件のときだけ使える
  • 工程のラインに置く専用治具

パーソナルスキル

  • 自分の設定側の ~/.claude/skills/
  • どの案件を開いても使える
  • 持ち歩く自分の工具箱

今日は User scope（自分だけで使う）を選んでください
